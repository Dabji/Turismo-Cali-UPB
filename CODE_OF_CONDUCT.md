# 🌿 Código de Conducta / Code of Conduct

> **ES:** Este proyecto es académico y público; cuidamos el respeto, la claridad y la colaboración técnica.
> **EN:** This project is academic and public; we value respect, clarity, and technical collaboration.

---

## 🤝 Compromiso / Our pledge

**ES:** Nos comprometemos a mantener un espacio abierto, respetuoso e inclusivo para estudiantes, docentes y colaboradores.
**EN:** We pledge to maintain an open, respectful, and inclusive space for students, teachers, and contributors.

---

## ✅ Comportamientos esperados / Expected behavior

| ES | EN |
|---|---|
| Ser respetuoso en discusiones técnicas. | Be respectful in technical discussions. |
| Dar retroalimentación concreta y accionable. | Give concrete and actionable feedback. |
| Cuidar la seguridad del repositorio público. | Protect the security of the public repository. |
| Documentar decisiones importantes. | Document important decisions. |
| Reconocer errores y corregirlos con evidencia. | Acknowledge mistakes and fix them with evidence. |

---

## 🚫 Comportamientos no aceptados / Unacceptable behavior

| ES | EN |
|---|---|
| Comentarios ofensivos, discriminatorios o intimidantes. | Offensive, discriminatory, or intimidating comments. |
| Publicación de secretos, credenciales o datos sensibles. | Publishing secrets, credentials, or sensitive data. |
| Ataques personales en revisiones de código. | Personal attacks in code reviews. |
| Desinformación deliberada sobre evidencias técnicas. | Deliberate misinformation about technical evidence. |

---

## 🛠️ Aplicación / Enforcement

**ES:** Los mantenedores pueden solicitar cambios, cerrar conversaciones, retirar contenido o limitar la participación cuando se incumpla este código.
**EN:** Maintainers may request changes, close conversations, remove content, or limit participation when this code is violated.

---

## 📬 Contacto / Contact

**ES:** Para reportar un problema de conducta, contacta a los mantenedores del repositorio.
**EN:** To report a conduct issue, contact the repository maintainers.
